# 飞书开放平台配置指南

本文档详细说明如何在飞书开放平台配置文档插件应用。

## 前置准备

- 飞书企业账号 (企业管理员权限)
- 通义千问API Key
- 部署好的后端服务地址

## 第一步: 创建企业自建应用

### 1. 访问飞书开放平台

访问: https://open.feishu.cn/

点击右上角"开发者后台"登录

### 2. 创建应用

1. 点击"创建企业自建应用"
2. 填写应用信息:
   - **应用名称**: AI文档一键排版 (或您自定义的名称)
   - **应用描述**: 基于AI的智能文档格式优化工具
   - **应用图标**: 上传120x120px的图标

3. 点击"创建"

### 3. 记录应用凭证

创建成功后,在"凭证与基础信息"页面记录:
- **App ID**: cli_xxxxxxxxxxxxx
- **App Secret**: 点击"查看"获取

⚠️ **重要**: 请妥善保管这些凭证,不要泄露！

## 第二步: 添加应用能力

### 1. 添加文档插件能力

1. 进入应用详情页
2. 点击左侧"应用能力" → "添加应用能力"
3. 选择 **"文档小组件 (Docs add-on)"**
4. 点击"添加"

### 2. 配置插件信息

在文档小组件配置页面:

#### 基础信息
- **插件名称**: AI文档一键排版
- **插件ID**: (自动生成)
- **插件描述**:
  ```
  一键优化文档格式，让您的文档更专业、更易读！

  功能特点:
  • 智能识别并转换列表
  • 自动添加高亮提示块
  • 结构化数据转表格
  • 优化文档标题层级
  ```

#### 插件图标
- 上传 64x64px 的图标
- 格式: PNG, 透明背景

#### 插件截图
上传 3-5 张功能截图 (建议尺寸: 1200x800px):
1. 插件主界面截图
2. 分析结果展示
3. 优化前后对比
4. 应用效果展示

### 3. 配置插件地址

#### 开发环境
- **插件地址**: http://localhost:3000 (本地开发)
- 用于开发调试

#### 生产环境
- **插件地址**: https://your-domain.com/formatter
- 部署后的实际地址
- 必须使用HTTPS

### 4. 配置回调地址 (可选)

如果需要OAuth认证:
- **Redirect URL**: https://your-domain.com/callback

## 第三步: 申请API权限

### 1. 进入权限管理

点击左侧"权限管理"

### 2. 申请必要权限

搜索并申请以下权限:

| 权限名称 | 权限描述 | 用途 |
|---------|---------|------|
| `docx:document` | 查看、编辑和管理云空间中的文档 | 读取和修改文档内容 |
| `docx:document:readonly` | 查看云空间中的文档 | 读取文档内容 |

### 3. 提交申请

- 填写申请理由: "需要读取和优化文档格式"
- 等待管理员审批 (通常几分钟内)

### 4. 查看权限状态

在"权限管理"页面查看申请状态:
- ✅ 绿色: 已通过
- ⏳ 黄色: 待审批
- ❌ 红色: 已拒绝

## 第四步: 配置应用可见范围

### 1. 进入可用性设置

点击左侧"应用发布" → "可用性"

### 2. 配置可见范围

选择以下之一:
- **全员可见**: 企业所有成员可用
- **部分可见**: 指定部门/人员可用
- **仅管理员**: 仅管理员可见 (用于测试)

测试阶段建议选择"仅管理员"

### 3. 保存配置

## 第五步: 测试插件

### 1. 在文档中添加应用

1. 打开任意飞书文档
2. 点击右上角 `···` → "更多"
3. 选择 "添加文档应用"
4. 搜索您的应用名称
5. 点击"添加"

### 2. 测试插件功能

1. 在文档中输入 `/`
2. 搜索您的插件
3. 点击打开
4. 测试各项功能:
   - 文档分析
   - 优化建议
   - 应用优化

### 3. 查看日志

在开发者后台查看:
- API调用日志
- 错误日志
- 性能数据

## 第六步: 配置Webhook (可选)

如果需要接收事件通知:

### 1. 进入事件订阅

点击左侧"事件订阅"

### 2. 配置请求地址

- **请求URL**: https://your-domain.com/webhook
- **Token**: (自动生成)
- **Encrypt Key**: (自动生成)

### 3. 订阅事件

选择需要的事件:
- 文档创建
- 文档更新
- 文档删除

### 4. 验证配置

系统会发送验证请求,确保您的服务器正确响应。

## 第七步: 发布应用

### 1. 准备发布材料

#### 必需材料:
- ✅ 应用图标 (120x120px)
- ✅ 应用截图 (3-5张, 1200x800px)
- ✅ 应用描述 (详细功能说明)
- ✅ 使用文档/帮助链接
- ✅ 隐私政策链接
- ✅ 服务条款链接

#### 应用描述模板:
```markdown
# AI文档一键排版

让文档编辑更高效,让内容呈现更专业！

## 核心功能

🎯 **智能列表转换**
自动识别并列内容,转换为清晰的列表格式

💡 **重点内容突出**
为重要提示自动添加高亮块,让关键信息不被忽略

📊 **数据结构化**
将分散的数据自动整理成规范的表格

📑 **标题层级优化**
智能调整文档结构,建立清晰的内容层次

## 使用场景

✅ 会议纪要整理
✅ 项目文档编写
✅ 工作汇报美化
✅ 知识库维护

## 特色优势

• AI驱动,智能分析
• 实时预览,所见即所得
• 一键应用,秒级完成
• 支持撤销,安全可靠

## 使用方法

1. 在文档中输入 `/` 调出命令菜单
2. 选择 "AI文档一键排版"
3. 等待AI分析完成
4. 预览并选择优化建议
5. 点击"应用优化"完成

详细使用指南: [链接]

• 仅读取必要的文档结构
• 不存储任何文档内容
• 使用HTTPS加密传输
• 符合企业数据安全规范

## 联系我们

• 客服邮箱: support@example.com
• 用户社群: [飞书群链接]
• 问题反馈: [GitHub链接]
```

### 2. 提交审核

1. 点击"应用发布" → "版本管理"
2. 点击"创建版本"
3. 填写版本信息:
   - 版本号: 1.0.0
   - 更新说明: 首次发布
4. 上传所有材料
5. 点击"提交审核"

### 3. 等待审核

- 审核时间: 通常1-3个工作日
- 审核结果会通过邮件和站内信通知
- 可能的结果:
  - ✅ 通过: 可以发布到应用中心
  - 📝 需要修改: 按要求修改后重新提交
  - ❌ 拒绝: 查看拒绝原因并整改

### 4. 正式发布

审核通过后:
1. 点击"发布"按钮
2. 选择发布范围:
   - 企业内部: 仅本企业可见
   - 应用中心: 所有飞书用户可见
3. 确认发布

🎉 **恭喜!** 您的应用已成功发布！

## 常见问题

### Q1: 审核被拒绝怎么办?
**A**: 查看拒绝原因,常见问题:
- 应用描述不清晰 → 补充详细说明
- 截图不符合要求 → 重新制作
- 功能不完善 → 完善后重新提交
- 安全问题 → 整改安全隐患

### Q2: 如何更新应用配置?
**A**:
1. 在开发者后台修改配置
2. 测试环境验证
3. 如果是重大变更,需要重新审核

### Q3: App Secret泄露怎么办?
**A**:
1. 立即在开发者后台重置Secret
2. 更新后端配置
3. 重新部署服务

### Q4: 如何添加测试用户?
**A**:
1. 进入"可用性"设置
2. 添加测试用户邮箱
3. 用户即可在文档中使用

### Q5: 插件无法加载?
**A**: 检查:
- 插件地址是否正确
- 服务器是否正常运行
- HTTPS证书是否有效
- CORS配置是否正确

## 安全建议

### 环境变量管理
```bash
# .env
FEISHU_APP_ID=cli_xxxxx
FEISHU_APP_SECRET=xxxxx  # 不要提交到Git!

# .gitignore
.env
.env.local
.env.production
```

### API密钥安全
- ❌ 不要在前端代码中暴露Secret
- ❌ 不要提交到代码仓库
- ✅ 使用环境变量
- ✅ 定期轮换密钥
- ✅ 为不同环境使用不同密钥

### 权限最小化
- 只申请必要的权限
- 定期审核权限使用情况
- 及时移除不需要的权限
