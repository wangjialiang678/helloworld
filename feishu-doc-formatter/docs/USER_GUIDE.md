# 用户使用指南

欢迎使用飞书文档一键排版插件！本指南将帮助您快速上手。

## 功能概述

AI文档一键排版插件可以帮助您:
- ✅ 自动识别并转换为列表格式
- ✅ 为重要内容添加高亮提示块
- ✅ 将结构化数据转换为表格
- ✅ 优化文档标题层级
- ✅ 提升文档专业性和可读性

## 安装插件

### 方式一: 从飞书应用中心安装 (推荐)

1. 打开飞书应用中心
2. 搜索 "AI文档一键排版" 或 "智能文档美化"
3. 点击 "添加" 按钮
4. 授权插件访问文档权限
5. 安装完成！

### 方式二: 企业自建应用

如果您的企业有专属部署,请联系管理员获取安装链接。

## 使用方法

### 第一步: 在文档中调用插件

有三种方式可以调用插件:

#### 方式 1: 斜杠命令 (推荐)
1. 在文档中输入 `/`
2. 在弹出的菜单中搜索 "一键排版"
3. 点击插件图标

#### 方式 2: 加号按钮
1. 在文档中点击 `+` 按钮
2. 选择 "小组件"
3. 找到 "AI文档一键排版"

#### 方式 3: 文档菜单
1. 点击文档右上角的 `···` (更多)
2. 选择 "小组件"
3. 找到 "AI文档一键排版"

### 第二步: 等待AI分析

插件会自动分析您的文档:
- ⏱️ 分析时间: 通常5-10秒
- 📊 显示进度: 实时显示分析状态
- 🤖 AI工作: 识别可优化的内容

### 第三步: 查看优化建议

分析完成后,您会看到:

#### 1. 总览信息
- 发现的可优化内容数量
- 预计优化效果评分 (0-100分)
- 优化前后对比

#### 2. 详细建议列表
每条建议包含:
- **当前格式** → **建议格式**
- **置信度**: AI对这个建议的信心程度
- **原因说明**: 为什么建议这样修改
- **预览对比**: 修改前后的效果预览

#### 3. 建议类型说明

| 图标 | 类型 | 说明 | 示例 |
|------|------|------|------|
| 📝 → 📋 | 列表转换 | 将并列内容转为列表 | "第一、第二、第三" → "• 第一<br>• 第二<br>• 第三" |
| 📝 → 💡 | 高亮块 | 突出重要提示 | "注意..." → "💡 注意..." |
| 📝 → 📊 | 表格转换 | 结构化数据转表格 | "A负责前端,B负责后端" → 表格 |
| 🔤 → 🔤 | 标题优化 | 调整标题层级 | H3 → H2 |

### 第四步: 选择要应用的建议

- **默认**: 所有建议都已选中
- **自定义**: 点击建议可取消选中
- **全选/取消**: 使用顶部的"全选"按钮

💡 **提示**:
- 绿色置信度 (>80%): 建议直接应用
- 黄色置信度 (60-80%): 建议查看预览后决定
- 可以先选择部分应用,其他的稍后再处理

### 第五步: 应用优化

1. 确认选择的建议
2. 点击右下角 "应用优化 (N)" 按钮
3. 等待应用完成 (通常3-5秒)
4. 文档自动刷新,显示优化效果

✅ **完成!** 您的文档已优化完毕！

## 配置选项

### 优化级别

您可以选择不同的优化级别:

#### 保守模式
- 只优化非常明确的内容
- 置信度要求 >85%
- 适合: 正式文档、汇报材料

#### 标准模式 (推荐)
- 平衡优化效果和安全性
- 置信度要求 >70%
- 适合: 大多数日常文档

#### 激进模式
- 最大化优化效果
- 置信度要求 >60%
- 适合: 草稿、内部文档

### 自定义规则

可以设置哪些类型的优化需要启用:
- ☑️ 列表转换
- ☑️ 表格转换
- ☑️ 高亮块转换
- ☑️ 标题优化

## 使用场景示例

### 场景 1: 会议纪要整理

**优化前:**
```
会议要点讨论了三个主要问题第一是项目进度第二是人员安排第三是预算控制
```

**优化后:**
```
会议要点讨论了三个主要问题:
• 项目进度
• 人员安排
• 预算控制
```

### 场景 2: 重要提示突出

**优化前:**
```
注意本文档包含敏感信息请勿外传
```

**优化后:**
```
⚠️ 注意：本文档包含敏感信息,请勿外传
```

### 场景 3: 数据结构化

**优化前:**
```
项目成员包括张三负责前端李四负责后端王五负责测试
```

**优化后:**
| 姓名 | 负责模块 |
|------|----------|
| 张三 | 前端 |
| 李四 | 后端 |
| 王五 | 测试 |

### 场景 4: 文档大纲优化

**优化前:**
```
项目概述 (H2)
  背景介绍 (H2)  ← 应该是H3
  目标说明 (H2)  ← 应该是H3
```

**优化后:**
```
项目概述 (H2)
  背景介绍 (H3)
  目标说明 (H3)
```

## 最佳实践

### ✅ 推荐做法

1. **定期优化**: 文档编写完成后使用插件统一优化
2. **预览确认**: 应用前仔细查看预览,确保符合预期
3. **分批应用**: 大文档可以分批次应用优化
4. **保存副本**: 重要文档建议先复制一份再优化
5. **标准模式**: 大多数情况使用标准优化级别

### ❌ 避免的做法

1. ~~盲目应用所有建议~~ → 应先查看预览
2. ~~在模板文档中使用~~ → 可能破坏格式
3. ~~频繁重复优化~~ → 一次优化即可
4. ~~跳过预览~~ → 可能出现意外效果

## 常见问题

### Q1: 为什么有些内容没有优化建议？
**A**: 可能原因:
- 内容已经是最佳格式
- AI置信度不够 (可尝试激进模式)
- 内容类型不支持优化

### Q2: 优化后效果不理想怎么办？
**A**:
1. 使用飞书的撤销功能 (Ctrl+Z / ⌘+Z)
2. 手动调整不满意的部分
3. 反馈给我们改进AI

### Q3: 插件会修改我的原始内容吗？
**A**:
- 不会修改文字内容
- 只会改变格式和结构
- 可以随时撤销

### Q4: 支持哪些类型的文档？
**A**: 支持所有飞书文档,包括:
- 普通文档
- 知识库文档
- 协作文档

**不支持:**
- 电子表格 (Spreadsheet)
- 多维表格 (Bitable)

### Q5: 分析很慢怎么办？
**A**:
- 检查网络连接
- 大文档(>500 Block)需要更长时间
- 可以考虑分段处理

### Q6: 数据安全吗？
**A**:
- ✅ 仅读取必要的文档结构信息
- ✅ 不存储文档内容
- ✅ 使用HTTPS加密传输
- ✅ 通过飞书官方API访问

### Q7: 免费吗？
**A**:
- 个人用户: 每月免费额度
- 企业用户: 根据企业套餐
- 详见定价页面
